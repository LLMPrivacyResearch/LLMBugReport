# Apache Bug Report Decomposition Replication Package

This repository contains the datasets, prompts, LLM outputs, and evaluation results used in our study.

## PQ

- **`Apache_Jira_Privacy_Bug_Report.csv`**  
  Contains the privacy-related Apache Jira bug reports used in the privacy experiments, including bug descriptions, priority, creation time, first comment time, resolution time, and original Jira links.

- **`Apache_Jira_Security_Bug_Report.csv`**  
  Contains the security-related Apache Jira bug reports collected for the security experiment.

## RQ1

- **`RQ1_ChatGPT.csv`**  
  Contains the zero-shot decomposition results generated by ChatGPT-4o and the corresponding manual evaluation results.

- **`RQ1_DeepSeek.csv`**  
  Contains the zero-shot decomposition results generated by DeepSeek-v1 and the corresponding manual evaluation results.

- **`RQ1_Zero-shot_Prompting.txt`**  
  Contains the complete zero-shot prompt used in RQ1.

## RQ2

- **`RQ2_ChatGPT.csv`**  
  Contains the few-shot decomposition results generated by ChatGPT-4o and the corresponding manual evaluation results.

- **`RQ2_DeepSeek.csv`**  
  Contains the few-shot decomposition results generated by DeepSeek-v1 and the corresponding manual evaluation results.

- **`RQ2_Few-shot_Prompting.txt`**  
  Contains the complete 4-shot prompt used in RQ2, including the four demonstration examples.

## RQ3

- **`Prompts of RQ3.docx`**  
  Contains the prompts used in RQ3 for zero-shot, few-shot, Chain-of-Thought, and Persona-based prompting.

- **`API settings.docx`**  
  Contains the model and API settings used in the experiments, including model identifiers, API providers, access dates, and decoding configurations.
